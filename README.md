# 給食畑サイト

現在の公開サイトをもとに、まず `schedule.html` を編集できる形で復元したリポジトリです。

## 今回の構成

- `schedule.html` — 栽培予定・過去の栽培記録・Googleカレンダー
- `schedule.js` — 今期に育てる作物、過去のガント表・月別リストのデータ
- `schedule.css` — 表示デザイン

## 今期の予定を更新する場所

`schedule.js` の先頭にある `planCrops` を更新します。播種・定植・収穫の日付が決まったら、週別ガント表用のデータをここへ追加します。

## 過去の記録を残す方法

栽培が一区切りしたら、その期のデータを `archiveRows` と `archiveMonths` に残し、`2026年春作` と同じようにタブを1つ追加します。現在の記録を上書きしないことで、過去の予定も見返せます。

## 公開について

このリポジトリには、今回対象のスケジュールページを復元しています。既存のトップページと画像を含めてNetlifyへ公開し直す前に、トップページのソース一式もこのリポジトリへ移す必要があります。
