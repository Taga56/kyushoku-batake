# 給食畑サイト

公開するトップページとスケジュールページを、同じ公開ルートで管理するリポジトリです。

## 今回の構成

- `index.html` — 給食畑のトップページ
- `schedule.html` — 栽培予定・過去の栽培記録・Googleカレンダー
- `schedule.js` — 今期に育てる作物、今期／過去のガント表・月別リストのデータ
- `archive/2026-09-29-live-site/` — 公開前のサイト一式と画像のバックアップ

## 今期の予定を更新する場所

`schedule.js` の先頭にある `planCrops` を更新します。週別の予定は `planColumns` と `planRows` に記録します。播種・定植・収穫・出荷の日付が決まったら、ここを更新します。

## 過去の記録を残す方法

栽培が一区切りしたら、その期のデータを `archiveRows` と `archiveMonths` に残し、`2026年春作` と同じようにタブを1つ追加します。現在の記録を上書きしないことで、過去の予定も見返せます。

## 公開について

`index.html` と `schedule.html` は同じ階層にあり、トップページからスケジュールへ移動できます。トップページは、バックアップ内に保持している画像を参照します。
