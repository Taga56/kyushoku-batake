# 給食畑サイト

公開するトップページとスケジュールページを、同じ公開ルートで管理するリポジトリです。

## 今回の構成

- `公開用/` — アップロードするファイル一式。このフォルダだけを公開します。
  - `index.html` — 給食畑のトップページ
  - `schedule.html` — 栽培予定・過去の栽培記録・Googleカレンダー
  - `assets/css/` — 各ページのスタイルシート
  - `assets/js/` — 各ページのJavaScript
  - `assets/images/` — トップページで使う画像
- `archive/2026-09-29-live-site/` — 公開前のサイト一式と画像のバックアップ

## 今期の予定を更新する場所

`公開用/assets/js/schedule.js` の先頭にある `planCrops` を更新します。週別の予定は `planColumns` と `planRows` に記録します。播種・定植・収穫・出荷の日付が決まったら、ここを更新します。

## 過去の記録を残す方法

栽培が一区切りしたら、その期のデータを `archiveRows` と `archiveMonths` に残し、`2026年春作` と同じようにタブを1つ追加します。現在の記録を上書きしないことで、過去の予定も見返せます。

## 公開について

Netlifyでは `公開用` フォルダをそのままドラッグ＆ドロップして公開します。`archive` は公開用フォルダの外にあるため、誤ってアップロードされません。
